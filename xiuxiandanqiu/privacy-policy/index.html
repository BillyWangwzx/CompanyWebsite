修仙弹球隐私政策

更新日期：2026年10月21日

生效日期：2026年10月21日

三达不溜点游戏工作室（地址：北京市房山区良乡书院南街10号院1号楼12层1207，以下简称“我们”）是《修仙弹球》（以下简称“本游戏”）的运营者。本政策说明您使用本游戏及联系我们时，相关信息的处理方式，以及您享有的权利。

我们依据《中华人民共和国个人信息保护法》等适用法律法规，遵循合法、正当、必要和诚信原则处理个人信息。本政策适用于当前单机版本；应用商店、操作系统及其他第三方独立提供的服务，同时适用其各自的隐私规则。

请先了解：当前版本不提供游戏账号注册、第三方账号登录、云存档、社交聊天或游戏内支付，未接入广告、广告归因或第三方行为统计 SDK。游戏进度与设置默认保存在您的设备本地，不会自动上传至我们的服务器。主动联系客服、浏览本协议网页时会涉及相应的信息处理，详见下文。

阅读本政策或接受服务条款，不代表您同意任何非必要的个人信息处理。依法需要同意的处理活动，我们会事先告知并取得相应同意；您拒绝非必要的信息处理，不影响单机基本功能。

一、我们如何处理信息

1. 游戏进度与设置

为保存并恢复游戏体验，本游戏在设备本地读写关卡进度、通关记录、游戏内晶石余额、修行属性与境界、法宝收藏与配装、当前战斗状态，以及音乐和音效设置。这些数据用于关卡挑战、成长计算、结算和续玩，当前不会与手机号、实名身份或第三方账号关联，也不会自动发送给我们。

2. 运行环境与设备信息

本游戏使用 Godot Engine。运行时，引擎会在设备本地使用操作系统、屏幕尺寸、图形与音频设备等运行环境信息，以完成画面显示、输入处理、声音播放和设备适配。本游戏未接入自动上传设备信息、游戏行为或崩溃报告的服务。

关于 Android ID：Godot 在 Android 平台提供设备标识接口，部分引擎版本会在初始化时通过系统接口读取 Android ID 并作本地缓存。当前游戏业务不主动调用该设备标识接口，不将 Android ID 用于广告、用户画像或向我们的服务器上报。我们不会通过游戏业务读取 IMEI、IMSI、OAID、广告标识符、通讯录或已安装应用列表。

3. 您主动提供的客服信息

当您通过邮件咨询、反馈故障或提出隐私请求时，我们会收到您的邮件地址、邮件内容及您主动附上的截图、日志、游戏版本、设备型号或系统版本。这些信息仅用于沟通、排查问题、处理您的请求及依法处理争议。请先遮盖与问题无关的个人信息；我们不要求您提供账号密码、完整身份证件或银行卡信息。

客服信息的处理以响应您主动提出的请求所必需或您的同意为基础。若缺少定位问题所必需的说明，我们可能无法完成该项排查，但不会因此限制您使用单机游戏。

二、设备权限与本地存储

本游戏使用应用自身的存储空间保存游戏数据和设置，无需为基本玩法授予通讯录、短信、电话、精确位置、相机、麦克风或相册读取权限，也不会为了保存游戏进度要求访问您设备上的其他文件。

本地文件用于存档和偏好设置，不用于跨应用跟踪。当前版本没有网页广告 Cookie 或个性化推荐功能。浏览本政策、下载更新或发送客服邮件时，需要由浏览器、应用商店或邮件客户端连接网络；网络访问是否可单独关闭，由您的操作系统和相关应用决定。关闭网络不影响已经安装的当前单机版本的基本玩法。

后续如新增确需权限的功能，我们会在使用前说明权限名称、用途及拒绝的影响，并依法取得授权。您可以通过系统设置管理可用权限。

三、第三方组件与外部服务

  • Godot Engine：用于在设备本地运行游戏、渲染画面、处理输入、播放声音及读写存档。该引擎不作为本游戏的广告或行为统计服务；当前游戏未配置向 Godot 运营方自动上报玩家数据的功能。Android 平台设备标识情况见第一节。
  • 应用商店与操作系统：您下载、更新游戏或使用系统备份时，相关平台可能独立处理其账号、下载记录、诊断或备份信息。本游戏不会因此取得您的平台密码或支付资料，请通过相应平台查阅并管理其隐私设置。
  • 协议网页托管：本网站由 GitHub Pages 托管。您打开网页时，浏览器会向托管服务发送 IP 地址、请求时间、页面地址及浏览器提供的请求信息，用于传输网页和保障服务安全；托管服务可能在境外处理访问数据。请参阅 GitHub 隐私声明。本页面未嵌入广告、第三方统计脚本、远程字体或追踪像素。
  • 客服邮件：您发送邮件时，您使用的邮件服务及我们的收件服务会参与邮件传输和保存。我们只将收到的信息用于处理客服与隐私请求，不将其用于营销。

当前版本未集成 TapTap 登录、广告、支付或第三方统计 SDK。若未来接入，我们会在启用前更新具体提供方、信息种类、用途、处理方式和隐私政策链接，并履行相应的告知及同意义务。

四、保存地点与期限

游戏存档与设置保存在您正在使用的设备上，通常保留至您删除应用数据、删除相应存档或卸载游戏。当前不提供我们的云存档服务，我们无法从服务器为您恢复已删除的本地进度。若您开启了操作系统或设备厂商的备份功能，备份副本的保存和删除请在相应平台中另行管理。

客服与隐私请求记录保存在我们使用的客服邮箱及必要的处理记录中，通常在请求处理结束后保留不超过十二个月，以便回访和处理后续问题；您可申请提前删除。法律法规要求保存或处理未结争议确需继续保留的，仅在必要范围及期限内保存，期限届满后删除或匿名化。

我们不会主动将本地游戏存档传输至境外。您浏览 GitHub Pages 网页或使用外部邮件、系统备份等服务时，相关数据的保存地点与期限由对应服务的规则及您的设置决定。若我们今后因业务需要向境外提供个人信息，会事先履行适用法律要求的告知、单独同意及其他必要程序。

五、共享、转让与公开披露

我们不出售、出租您的个人信息，也不向广告商提供本地存档或客服信息。除为处理您请求所必需的邮件服务、依法履行法定义务等情形外，不会向其他个人信息处理者提供您的信息；依法需要单独同意时，我们会先告知接收方、用途、方式及信息种类，并取得您的单独同意。

如因合并、分立、解散等原因确需转移我们持有的个人信息，我们会告知接收方的名称和联系方式，并要求其继续履行保护义务；接收方改变原处理目的或方式时，应依法重新取得您的同意。除取得您的单独同意或法律法规另有规定外，我们不会公开披露您的个人信息。

六、信息安全

我们通过尽量减少数据收集、控制客服信息访问范围、限制保存期限等措施保护信息。请通过可信渠道下载游戏，保护设备与邮箱安全，并在向他人发送截图或日志前检查其中的个人信息。

如发生涉及我们持有的个人信息的安全事件，我们会及时采取补救措施，并依照法律要求向有关主管部门报告、向受影响用户告知事件情况和可采取的措施。

七、您的权利与删除方式

  • 查阅与更正：您可以在游戏内查看现有进度和调整声音设置；对我们持有的客服信息，可通过邮件申请查阅、复制、补充或更正。
  • 删除本地数据：在支持该功能的设备上，通过“系统设置 → 应用 → 修仙弹球 → 存储 → 清除数据”，或卸载游戏，删除应用本地数据。不同系统的名称可能不同；桌面版本可删除游戏用户数据目录。操作前请确认，删除后可能无法恢复。
  • 删除我们持有的信息：请通过下方邮箱提出请求，并说明希望删除的客服记录。我们会在合理核实您与该记录的关联后处理，不会要求提供与验证无关的信息。
  • 撤回同意与限制处理：您可停止提供可选客服资料，并通过邮件撤回对相关可选处理的同意或要求限制处理。撤回不影响此前依法进行的处理；依法应当继续保存的，我们将停止除存储和必要安全保护以外的处理。
  • 账号与解释说明：当前无本游戏账号，无需办理游戏账号注销；删除本地数据不等于注销应用商店或其他平台账号。您可以请求我们解释本政策，并依法申请其他个人信息权利。

我们一般在收到请求并完成必要身份核实后十五个工作日内回复。合理请求原则上不收费；如依法无法满足，我们会说明理由。您也可以向有权监管部门投诉，或依法向有管辖权的人民法院寻求救济。

八、未成年人保护

未满十八周岁的用户应在监护人指导下阅读本政策并合理安排游戏时间。当前版本不设置面向儿童的账号、社交或个人信息采集功能。

不满十四周岁的用户请由监护人代为联系客服。确需处理不满十四周岁未成年人的个人信息时，我们将事先取得监护人同意，并按未成年人个人信息保护的特别要求，仅在明确、必要的范围内处理；发现未经监护人同意收集的相关信息后，我们会及时核实并删除，法律另有规定的除外。监护人可通过下方邮箱提出查询、更正或删除请求。

九、政策更新

我们可能根据功能变化和法律要求更新本政策，并在本页标注更新及生效日期。涉及新增登录、广告、支付、云存档、信息共享或其他对您权益有重大影响的变化时，我们会在相关功能启用前以显著方式告知；处理目的、方式或信息种类发生变化且依法需重新取得同意的，会重新取得您的同意。我们不会仅以您继续使用游戏推定您同意新增的个人信息处理。
