修仙弹球隐私政策

更新日期：2026年10月22日

三达不溜点游戏工作室（地址：北京市房山区良乡书院南街10号院1号楼12层1207，以下简称“我们”）是《修仙弹球》（以下简称“本游戏”）的运营者。本政策说明您使用本游戏及联系我们时，相关信息的处理方式，以及您享有的权利。

我们依据《中华人民共和国个人信息保护法》等适用法律法规，遵循合法、正当、必要和诚信原则处理个人信息。本政策适用于当前单机版本；应用商店、操作系统及其他第三方独立提供的服务，同时适用其各自的隐私规则。

请先了解：Android 版本使用 TapTap 账号登录后进入游戏。首次启动或协议更新需要重新取得同意时，会先显示 Android 原生隐私页；在您同意并成功保存同意记录前，不启动 Godot 游戏引擎或受保护的 TapSDK 启动组件。拒绝同意会退出游戏，您可在同意前阅读完整协议。当前不提供云存档、社交聊天或游戏内支付，未接入广告、广告归因或第三方行为统计 SDK；游戏进度与设置保存在设备本地，不自动上传至我们的服务器。

阅读本政策或接受服务条款，不代表您同意任何非必要的个人信息处理。依法需要同意的处理活动，我们会事先告知并取得相应同意；您拒绝非必要的信息处理，不影响基本服务。TapTap 登录所必需的信息与可选客服资料分别说明；拒绝提供完成登录必需的信息将无法使用 Android 版本的登录及游戏服务。

一、我们如何处理信息

1. 游戏进度与设置

为保存并恢复游戏体验，本游戏在设备本地读写关卡进度、通关记录、游戏内晶石余额、修行属性与境界、法宝收藏与配装、当前战斗状态，以及音乐和音效设置。这些数据用于关卡挑战、成长计算、结算和续玩，不会通过我们的服务器与手机号或实名身份关联，也不会自动发送给我们。TapTap 登录不会把本地进度变为云存档，切换账号不会自动同步或重置本机进度。

2. 运行环境与设备信息

本游戏使用 Godot Engine。运行时，引擎会在设备本地使用操作系统、屏幕尺寸、图形与音频设备等运行环境信息，以完成画面显示、输入处理、声音播放和设备适配。本游戏未接入自动上传设备信息、游戏行为或崩溃报告的服务。

关于 Android ID：Godot 在 Android 平台提供设备标识接口，本游戏使用的 Android 引擎在您通过原生隐私页同意后初始化，会通过系统接口读取 Android ID 并作本地缓存。当前游戏业务不主动调用该设备标识接口，不将 Android ID 用于广告、用户画像或向我们的服务器上报。我们不使用该标识进行跨应用跟踪。当前游戏业务不读取 IMEI、IMSI、OAID、广告标识符、通讯录或完整已安装应用列表。

3. TapTap 账号登录

Android 版本通过易玩（上海）网络科技有限公司提供的 TapTap 登录 SDK（TapSDK core + login 4.10.7）完成账号授权和身份验证。您同意本政策后，相关启动组件与 SDK 才会初始化；您主动点击“TapTap 登录”后，SDK 请求 public_profile 授权，处理 TapTap 账号标识（OpenID、UnionID）及用于维持登录状态的授权凭据。当前登录桥只向游戏业务返回账号标识，游戏业务只使用 OpenID 识别登录状态，不读取昵称、头像或您的手机号码，不将授权令牌写入游戏存档或日志，不获取您的 TapTap 密码，也不自行要求手机号注册。

根据 TapSDK 的处理规则，SDK 在初始化、登录及维护服务期间会通过系统接口处理 Android ID、操作系统版本、设备型号、CPU 信息、设备内存信息和网络类型等设备与网络信息，用于账号登录、设备兼容、故障排查及服务安全；联网请求还涉及 IP 地址和必要的访问记录。具体规则见第三节的 SDK 隐私政策。完成登录必须连接网络；不授权账号登录或网络不可用时，可能无法进入 Android 游戏。桌面开发版本不使用该 Android 登录 SDK。

我们不直接收集您的姓名或身份证件号码，也未接入 TapTap 合规认证、广告、云存档或数据分析等其他扩展模块。TapTap 自身账号涉及实名、未成年人或平台账号安全的信息处理，由其依据适用法律及平台规则另行说明。本政策不将登录授权视为对其他扩展服务的授权。

4. 您主动提供的客服信息

当您通过邮件咨询、反馈故障或提出隐私请求时，我们会收到您的邮件地址、邮件内容及您主动附上的截图、日志、游戏版本、设备型号或系统版本。这些信息仅用于沟通、排查问题、处理您的请求及依法处理争议。请先遮盖与问题无关的个人信息；我们不要求您提供账号密码、完整身份证件或银行卡信息。

客服信息的处理以响应您主动提出的请求所必需或您的同意为基础。若缺少定位问题所必需的说明，我们可能无法完成该项排查，但不会因此限制您使用单机游戏。

二、设备权限与本地存储

本游戏使用应用自身的存储空间保存游戏数据和设置，无需为基本玩法授予通讯录、短信、电话、精确位置、相机、麦克风或相册读取权限，也不会为了保存游戏进度要求访问您设备上的其他文件。

本地存储还保存已接受的协议版本、同意时间和政策配置指纹；TapSDK 在应用存储空间内维护登录缓存。原生同意记录用于在协议变化时重新提示，不用于广告。清除应用数据或卸载游戏会同时影响这些记录和游戏进度。

本地文件用于存档和偏好设置，不用于跨应用跟踪。当前版本没有网页广告 Cookie 或个性化推荐功能。TapTap 登录需要 INTERNET 网络访问权限，相关网络状态检测使用 ACCESS_NETWORK_STATE 权限；两者是 Android 普通权限，通常不触发系统运行时授权弹窗，是否可单独关闭由设备系统决定。关闭网络可能使登录或登录状态验证无法完成，进而无法进入 Android 游戏。浏览本政策、下载更新或发送客服邮件时，也需要浏览器、应用商店或邮件客户端连接网络。

后续如新增确需权限的功能，我们会在使用前说明权限名称、用途及拒绝的影响，并依法取得授权。您可以通过系统设置管理可用权限。

三、第三方组件与外部服务

  • Godot Engine：用于在设备本地运行游戏、渲染画面、处理输入、播放声音及读写存档。该引擎不作为本游戏的广告或行为统计服务；当前游戏未配置向 Godot 运营方自动上报玩家数据的功能。Android 平台设备标识情况见第一节。
  • TapTap 登录 SDK（TapSDK core + login 4.10.7）：提供方为易玩（上海）网络科技有限公司，用途为账号授权登录、登录状态维护、设备适配、故障排查与服务安全。处理范围包括第一节所列账号授权资料、设备信息及必要网络信息；通过系统接口、账号授权接口及网络请求处理。我们在原生隐私同意后才启用相关组件。详见 TapSDK 隐私政策。
  • 应用商店与操作系统：您下载、更新游戏或使用系统备份时，相关平台可能独立处理其账号、下载记录、诊断或备份信息。本游戏不会因此取得您的平台密码或支付资料，请通过相应平台查阅并管理其隐私设置。
  • 协议网页托管：本网站由 GitHub Pages 托管。您打开网页时，浏览器会向托管服务发送 IP 地址、请求时间、页面地址及浏览器提供的请求信息，用于传输网页和保障服务安全；托管服务可能在境外处理访问数据。请参阅 GitHub 隐私声明。本页面未嵌入广告、第三方统计脚本、远程字体或追踪像素。
  • 客服邮件：您发送邮件时，您使用的邮件服务及我们的收件服务会参与邮件传输和保存。我们只将收到的信息用于处理客服与隐私请求，不将其用于营销。

当前仅接入 TapTap 登录所需的 core 和 login 模块，不使用 TapTap 广告、支付、云存档、内嵌动态或数据分析扩展服务。若未来新增相关功能，会在启用前更新具体提供方、信息种类、用途、处理方式和隐私政策链接，并履行相应告知及同意义务。

四、保存地点与期限

游戏存档与设置保存在您正在使用的设备上，通常保留至您删除应用数据、删除相应存档或卸载游戏。当前不提供我们的云存档服务，我们无法从服务器为您恢复已删除的本地进度。若您开启了操作系统或设备厂商的备份功能，备份副本的保存和删除请在相应平台中另行管理。

登录信息与隐私同意记录在本应用的设备存储空间内由 SDK 和原生同意组件分别维护。退出登录会清除当前游戏登录状态并调用 SDK 退出登录接口；撤回隐私同意会退出登录、删除本机同意记录并关闭游戏，下次启动重新显示原生隐私页。本地进度不因退出登录或撤回同意被删除。TapTap 在其服务端持有的账号、授权和安全记录，其保存地点及期限请参阅 TapSDK 隐私政策并向 TapTap 行使相应权利。

客服与隐私请求记录保存在我们使用的客服邮箱及必要的处理记录中，通常在请求处理结束后保留不超过十二个月，以便回访和处理后续问题；您可申请提前删除。法律法规要求保存或处理未结争议确需继续保留的，仅在必要范围及期限内保存，期限届满后删除或匿名化。

我们不会主动将本地游戏存档传输至境外。您浏览 GitHub Pages 网页或使用外部邮件、系统备份等服务时，相关数据的保存地点与期限由对应服务的规则及您的设置决定。若我们今后因业务需要向境外提供个人信息，会事先履行适用法律要求的告知、单独同意及其他必要程序。

五、共享、转让与公开披露

我们不出售、出租您的个人信息，也不向广告商提供本地存档或客服信息。我们会为实现您授权的登录，与 TapTap 登录服务提供方交互必要的账号、设备及网络信息，具体范围见第一节和第三节。除前述登录、为处理您请求所必需的邮件服务、依法履行法定义务等情形外，不会向其他个人信息处理者提供您的信息；依法需要单独同意时，我们会先告知接收方、用途、方式及信息种类，并取得您的单独同意。

如因合并、分立、解散等原因确需转移我们持有的个人信息，我们会告知接收方的名称和联系方式，并要求其继续履行保护义务；接收方改变原处理目的或方式时，应依法重新取得您的同意。除取得您的单独同意或法律法规另有规定外，我们不会公开披露您的个人信息。

六、信息安全

我们通过尽量减少数据收集、控制客服信息访问范围、限制保存期限等措施保护信息。请通过可信渠道下载游戏，保护设备与邮箱安全，并在向他人发送截图或日志前检查其中的个人信息。

如发生涉及我们持有的个人信息的安全事件，我们会及时采取补救措施，并依照法律要求向有关主管部门报告、向受影响用户告知事件情况和可采取的措施。

七、您的权利与删除方式

  • 查阅与更正：您可以在游戏内查看现有进度和调整声音设置；对我们持有的客服信息，可通过邮件申请查阅、复制、补充或更正。
  • 删除本地数据：在支持该功能的设备上，通过“系统设置 → 应用 → 修仙弹球 → 存储 → 清除数据”，或卸载游戏，删除应用本地数据。不同系统的名称可能不同；桌面版本可删除游戏用户数据目录。操作前请确认，删除后可能无法恢复。
  • 删除我们持有的信息：请通过下方邮箱提出请求，并说明希望删除的客服记录。我们会在合理核实您与该记录的关联后处理，不会要求提供与验证无关的信息。
  • 撤回同意与限制处理：您可停止提供可选客服资料，并通过邮件撤回对相关可选处理的同意或要求限制处理。Android 版本可从关卡首页右上角“账号”打开“撤回隐私同意并退出”；撤回后登录服务停止，游戏关闭，下次打开需重新阅读并同意政策。撤回不影响此前依法进行的处理；依法应当继续保存的，我们将停止除存储和必要安全保护以外的处理。
  • 账号与解释说明：本游戏使用 TapTap 账号登录，不另行建立独立注册账号。您可在关卡首页“账号”页面点击“退出登录”；退出后 Android 版本需重新登录才能进入游戏。本应用中的退出登录、撤回同意和删除本地数据，均不会注销 TapTap 账号本身；如需注销 TapTap 账号或管理平台授权，请按照 TapTap 提供的账号流程办理。您可以请求我们解释本政策，并依法申请其他个人信息权利。

我们一般在收到请求并完成必要身份核实后十五个工作日内回复。合理请求原则上不收费；如依法无法满足，我们会说明理由。您也可以向有权监管部门投诉，或依法向有管辖权的人民法院寻求救济。

八、未成年人保护

未满十八周岁的用户应在监护人指导下阅读本政策并合理安排游戏时间。我们不设置面向儿童的社交或个性化广告功能。TapTap 账号登录应遵守平台适用的年龄、监护授权及实名规则。

不满十四周岁的用户请由监护人代为联系客服。确需处理不满十四周岁未成年人的个人信息时，我们将事先取得监护人同意，并按未成年人个人信息保护的特别要求，仅在明确、必要的范围内处理；发现未经监护人同意收集的相关信息后，我们会及时核实并删除，法律另有规定的除外。监护人可通过下方邮箱提出查询、更正或删除请求。

九、政策更新

我们可能根据功能变化和法律要求更新本政策，并在本页标注更新及生效日期。涉及新增登录、广告、支付、云存档、信息共享或其他对您权益有重大影响的变化时，我们会在相关功能启用前以显著方式告知；处理目的、方式或信息种类发生变化且依法需重新取得同意的，会重新取得您的同意。我们不会仅以您继续使用游戏推定您同意新增的个人信息处理。
